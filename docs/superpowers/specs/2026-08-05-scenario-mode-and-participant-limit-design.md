# 情景模拟模式选择与对象额度设计

## 目标

让用户每次进入情景模拟页时都明确选择一个已有模式或创建自定义模式，同时在对话页保留醒目但紧凑的模式切换入口。免费版最多可使用两位情景模拟对象；更多对象只展示付费解锁提示，本次不接入真实支付。

## 页面交互

### 模式选择

- 每次创建 `ScenarioSimulationView` 时展示轻量模式选择弹层。
- 弹层列出所有已有模式，当前模式有明确选中状态，并提供“创建自定义模式”入口。
- 选择已有模式后关闭弹层并进入对话；创建自定义模式后自动选中新模式。
- 对话页右侧放置窄小的悬浮模式按钮，展示当前模式名称与图标。点击后重新打开同一模式选择弹层。
- 模式按钮覆盖在页面留白区域，不改变主要内容的垂直布局。

### 对话对象额度

- 免费版额度固定为两位情景模拟对象。
- 对象列表中的前两位为可用对象，其余对象保留可见，但显示锁定样式与付费标记。
- 点击锁定对象或在额度已满时创建自定义对象，展示升级提示弹层。
- 升级提示说明“免费版支持 2 位对话对象，升级后可解锁更多”。“了解升级”按钮仅关闭提示或保持展示效果，不发起支付、不跳转外部页面。
- 当前已选择对象在同步数据后仍保持可用，避免页面状态出现无效选择。

## 代码边界

- `ScenarioParticipantAccessPolicy` 负责免费额度和对象是否可用的纯逻辑。
- `ScenarioSimulationView` 管理模式选择弹层、升级提示弹层与相关状态。
- 模式选择和对象选择各自保持为独立 SwiftUI 组件，不改动实时语音与对话记录逻辑。

## 错误与边界处理

- 关系网少于两人时，现有 Soul 后备对象仍保证页面可用。
- 删除自定义对象后重新计算可用顺序。
- 新增或同步关系对象不会绕过两人额度；超额对象始终保持锁定。
- 本次不新增订阅状态、支付 SDK、服务端计费或持久化额度记录。

## 关键测试

只新增两项聚焦测试：

1. 免费额度允许索引 0 和 1，锁定索引 2 及之后的对象。
2. 两个对象名额已使用时不允许创建更多自定义对象。

实现后运行这两项相关测试，并进行一次项目编译验证。
