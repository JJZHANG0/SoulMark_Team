# SoulMark 头像、每日语录与界面简化设计

## 目标

在不改变 SoulMark 现有核心导航和视觉语言的前提下，完成以下改造：联系人支持可选头像并同步到后端；关系图谱中心显示当前用户昵称；首页从提供的 500 条双语语录中每天稳定展示一句；底部导航缩小并增加屏幕边距；移除无功能意义的装饰线，使界面更简约。

## 范围

### 联系人头像

- 添加联系人时提供可跳过的头像选择入口。
- 使用 iOS 系统相册选择器获取图片，上传前按正方形方向处理、限制尺寸并压缩为 JPEG。
- 联系人详情页允许添加、更换和删除头像。
- 有头像时，关系图节点与联系人详情均显示真实头像；没有头像时继续显示当前关系分类颜色与 SF Symbol 占位头像。
- 后端提供需要登录鉴权的头像上传和删除接口，并验证联系人归属于当前用户。
- 图片初期保存到后端本地 `uploads/avatars` 目录，数据库沿用现有 `contacts.avatar_url` 字段保存可访问地址。
- 上传文件使用服务器生成的不可预测文件名，不信任客户端文件名；只接受 JPEG、PNG 和 HEIC 等可识别图片，限制请求体大小。
- 替换或删除头像后清理旧文件；联系人的删除流程也清理对应头像。
- 静态图片通过后端 `/media/avatars/...` 路径提供。存储实现与接口层分离，以便以后替换为阿里云 OSS。

## 用户昵称与关系图中心

- `ContentView` 将当前 `AppSession.user.displayName` 传给关系图页面。
- `RelationshipMapView` 和 `CenterProfile` 接收昵称，不再使用写死的 `Elias`。
- 昵称为空时使用本地化兜底名称“我 / Me”。
- 长昵称限制为单行，并缩放字体避免破坏中心节点布局。

## 每日语录

- 从用户提供的 `500_Authentic_Quotes_English_Chinese_Sourced.docx` 提取 500 条记录。
- 每条记录包含稳定 ID、英文正文、中文译文和出处，保存为 App Bundle 内的 JSON 资源。
- 启动时由专门的语录仓库读取并校验 JSON；读取失败时使用少量内置兜底语录，避免首页空白。
- 使用用户 UUID 与本地日历日期共同计算稳定索引。同一用户同一天无论刷新或重启 App 都看到同一句；日期变化后切换。
- 中文界面显示中文正文，英文界面显示英文正文。
- 出处显示在正文下方，使用更小、更淡的文字，不作为视觉重点。
- 分享内容包含当前语言正文、出处和 SoulMark 标记。
- 每日选择完全在设备端完成，不增加后端请求，离线时仍可使用。

## 底部导航

- 保留首页、图谱、模拟、复盘、我的五个入口及现有选择逻辑。
- 容器高度由 78 点缩小至约 68 点，内部图标、主操作按钮和留白按比例收紧。
- 水平外边距由 14 点增加到约 22 点，底部边距适当增加，使左右下圆角远离屏幕边缘。
- 保持磨砂材质、圆角轮廓和当前主题配色。

## 装饰线清理

- 移除全局页面背景左上角的粉色与灰色短线。
- 移除卡片或深色面板顶部的纯装饰短线。
- 移除底部导航顶部白色短线和模拟入口内部纯装饰短线。
- 保留具有结构或交互意义的元素，包括卡片轮廓、输入框边界、关系连接线、列表分隔线和选择状态边框。

## 数据流

### 新增联系人头像

1. 用户在新增联系人页选择或跳过头像。
2. App 先创建联系人，获得后端联系人 UUID。
3. 如果选择了图片，App 使用该 UUID 调用头像上传接口。
4. 后端验证联系人归属、校验并保存文件、更新 `avatar_url`，然后返回更新后的联系人。
5. App 用服务器响应更新关系图节点。

### 更新或删除头像

1. 用户在联系人详情页点击头像并选择更换或删除。
2. App 调用对应上传或删除接口。
3. 后端更新数据库并清理旧文件。
4. App 使用返回的联系人刷新详情页和关系图。

## 错误处理

- 用户取消选择图片时不显示错误，联系人仍可正常创建。
- 图片格式或大小不符合要求时，后端返回稳定错误结构，App 显示可理解的提示。
- 图片上传失败不撤销已经成功创建的联系人；App 保留默认头像，并允许用户稍后在详情页重试。
- 图片加载失败时自动回退到默认分类头像。
- 语录资源读取或记录校验失败时使用内置兜底语录。

## 测试与验收

- 后端测试头像上传、替换、删除、非法格式、超大文件和跨用户访问阻止。
- iOS 单元测试语录恰好为 500 条、字段非空、同用户同日期稳定、不同日期切换及语言选择。
- iOS 测试联系人响应正确映射 `avatar_url`，无头像时保持占位显示。
- 手工在真机验证新增联系人时跳过头像、选择头像、详情页更换与删除头像，以及 App 重启后的头像保留。
- 手工验证关系图中心昵称、首页每日语录出处、底部导航安全边距和所有目标装饰线已移除。
- 运行后端测试套件与 iOS 构建，确保现有注册、登录、联系人和实时语音功能不回归。

## 非目标

- 本次不接入阿里云 OSS、CDN、头像审核或社交头像抓取。
- 本次不允许拍照，只使用系统相册；相机入口可在后续版本增加。
- 本次不改动五个底部导航入口的信息架构。
