# SoulMark 四步新用户指引设计

## 目标

为新注册用户提供四页强制阅读的新手指引，说明 SoulMark 的核心使用方式。用户只需阅读并点击“下一步”，不需要在指引中真实创建人物、完成模拟或提交复盘。完成第四页后进入首页。

老用户不被强制展示；“设置”提供“重新查看新手指引”入口。等级里程碑徽章只出现在“我的 → 成就徽章”，关系成长卡仅展示经验、当前称号和下一个称号。

## 用户流程

新用户完成现有资料设置后进入独立的新手指引路由，不能跳过：

1. **关系图谱**：展示添加入口和人物卡示意，说明点击“添加”，填写名字、关系类型和备注，即可建立关系人物。
2. **情景模拟**：展示模拟对象和情景／提示词选择区域，说明可以切换对象和提示词，让 AI 按所选人物与情景回应。
3. **沟通复盘**：展示文字、聊天截图和语音三种输入方式，说明保存后会获得表达分析和改进建议。
4. **关系成长**：说明复盘与有效 AI 对话增加经验、升级门槛逐级提高、长期未使用会衰减，以及称号和等级徽章。主按钮改为“开始使用”。

每次点击“下一步”后服务端保存当前进度。退出 App 或换设备登录后继续未完成页。第四页完成后保存完成状态并进入首页。

## 账号与兼容规则

- 新增服务端字段 `tutorial_step`（0...4）与 `tutorial_completed_at`。
- 数据迁移把迁移时已经存在的账号设置为第 4 步完成，避免老用户被强制展示。
- 迁移后创建的新账号从第 0 步开始。
- 用户接口返回教程状态；新增认证接口更新下一步，只允许保持或前进，不能由客户端跳过多步。
- 指引首次强制流程没有关闭或跳过按钮；请求失败时停留当前页并提供重试。
- 设置中的“重新查看”使用本地重看状态，从第一页打开；不清除服务端完成状态，因此允许随时关闭并返回设置。
- 未升级的旧后端返回缺少教程字段时，客户端显示兼容错误，不把新用户误判为已完成。

## 客户端结构与展示

- App 路由新增 `tutorial`，位于现有资料设置和主界面之间。
- 新建独立的四页 SwiftUI 指引视图与纯数据页模型；页面样式沿用 SoulMark 背景、玻璃卡片、强调色和吉祥物。
- 页面含顶部 `1/4` 进度、标题、简短说明、功能示意区域和底部主按钮；第二页明确标注“切换对象”和“切换情景／提示词”。
- 支持中英文、日夜主题、动态字体、VoiceOver 和减少动态效果。
- 设置页新增“新手指引”入口。重看模式带关闭按钮，完成后返回设置。
- 关系成长卡不渲染等级徽章列表；现有成就弹窗集中展示等级徽章，并按历史最高等级永久保留解锁状态。

## 状态与错误处理

- 注册并完成资料设置后，根据服务端教程状态决定进入指引或主界面。
- 登录、冷启动和账号切换均使用当前账号的服务端状态，不复用上一个账号的进度。
- 点击按钮时显示提交中状态并防止重复点击；成功后进入下一页。
- 网络失败不前进，显示可重试提示。服务端接口需保证重复提交同一步骤是幂等的。
- 重看模式不调用进度接口，不影响强制流程或完成时间。

## 验证

- 后端测试覆盖：新账号默认未完成、旧账号迁移后完成、顺序推进、重复请求幂等、禁止跳步、账号隔离。
- iOS 测试覆盖：路由判断、四页内容和按钮文案、失败不前进、账号切换、重看不修改完成状态、设置入口。
- 模拟器检查中英文、日夜主题、大字体及四页布局。
- 完成后运行后端测试、静态检查和 iOS 单元测试，只提交本功能相关文件，并按用户授权推送 GitHub `main`。

## 范围限制

- 不要求用户在指引中执行真实业务操作。
- 不增加跳过按钮、额外奖励、教程完成经验或新的徽章类型。
- 不修改现有经验数值、升级或衰减规则。
